# 1L耐圧ペットボトル水やり器シミュレータ

密閉した1L耐圧ペットボトルの底面に小さな吐出口を複数開け、吐出口付近の土の乾湿によって
給水量が自動調整される「負圧式・水封式」の水やり器をブラウザ上でシミュレートします。

## 使い方

`watering-simulator/index.html` をWebブラウザで開くだけで動作します（サーバー不要・依存ライブラリなし）。

## 動作の仕組み（シミュレーションモデル）

1. **流出と負圧化** — ボトルは密閉されているため、水が流出するとボトル上部の空気層が膨張して
   負圧になり（ボイルの法則）、内圧＋水頭圧が外圧と釣り合ったところで流出が止まる。
2. **水封（湿った土）** — 吐出口の周囲の土が湿っている間は、土の吸引力（マトリックポテンシャル）が
   小さく、穴は水膜で塞がれて空気も侵入できないため、流出は停止したまま。
3. **流出再開（乾いた土）** — 植物の吸水や地表からの蒸発で土が乾くと、
   ①土の吸引圧が増して水を引き出し、②乾いた土の隙間から空気が穴に侵入して負圧が解除され、
   再び水が流出する。土が湿ると再び水封されて止まる。

土は2次元グリッド（1cmセル）で表現し、拡散・重力排水・地表蒸発・根の吸水（天候係数で変化）を
毎ステップ計算します。雨を選ぶと土が湿って流出が止まり、晴れが続くと流出が再開する様子が
観察できます。

## 操作できるパラメータ

| 項目 | 範囲 | 効果 |
|---|---|---|
| 吐出口の数 | 1〜7個 | 多いほど流出・空気侵入が起きやすい |
| 吐出口の直径 | 0.5〜2.0mm | 大きいほど流量が増える |
| 天候 | 曇り／晴れ／真夏／雨 | 蒸発散量（＝土の乾く速さ）が変わる |
| 土の種類 | 砂質土／壌土／粘土質 | 拡散速度・吸引圧・水封圧が変わる |
| シミュレーション速度 | ×60〜×3600 | 実時間1秒あたりの経過時間 |

## 参考値（初期設定：晴れ・壌土・φ1mm×3穴）

- 平均流出量：約120mL/日（1Lで7〜8日もつ）
- 土壌水分：27〜34%の帯域で自動調整
- ボトル内圧：−2〜−3.5kPa（ゲージ圧）
