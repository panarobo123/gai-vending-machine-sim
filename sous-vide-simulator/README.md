# 低温調理（Sous Vide）シミュレータ

食材（肉・魚・卵）を湯煎で低温調理するときの、内部温度の上昇と低温殺菌の進み具合を
ブラウザ上でシミュレートします。

## 使い方

`sous-vide-simulator/index.html` をWebブラウザで開くだけで動作します（サーバー不要・依存ライブラリなし）。

## 動作の仕組み（シミュレーションモデル）

1. **熱伝導** — 食材の厚み（または卵の半径）方向を一次元の格子に分割し、熱伝導方程式を
   差分法で解いています。肉・魚は平板、卵は球として近似しています。
2. **対流境界条件** — 食材の表面では、湯温との温度差に比例して熱が伝わると仮定しています
   （循環あり＝immersion circulatorを使うと熱伝達が強く、循環なし＝湯の対流のみに
   頼る場合は弱くなります）。湯温そのものは常に一定に保たれるものとします。
3. **低温殺菌の進行度** — 食材の中で最も加熱が遅れる中心温度の履歴を使い、D値・z値による
   一般化された対数減少（log10削減）モデルで、低温殺菌がどこまで進んだかを推定します。

温度の低い状態から湯につけると、表面から先に温まり、中心温度がゆっくり追いつく様子や、
中心温度が目標に達したあとも低温殺菌が進み続ける様子が観察できます。

## 操作できるパラメータ

| 項目 | 内容 |
|---|---|
| 食材 | 鶏むね肉／豚ロース／牛ステーキ／サーモン／卵（半熟卵） |
| 厚み（卵は直径） | 食材ごとの範囲内で調整可能 |
| 調理前の温度 | 冷蔵庫から出した直後の温度など |
| 目標中心温度 | 何℃まで中心を加熱したいか |
| 湯温 | 水槽（恒温水槽）の設定温度 |
| 循環方式 | 循環あり（immersion circulator）／循環なし |
| シミュレーション速度 | ×30〜×600（実時間1秒あたりの経過時間） |

## ⚠ 安全に関する注意

このシミュレータの低温殺菌の進行度（log10削減）は、教育・シミュレーション目的で用意した
簡略化された一般的なモデル（代表的な菌を想定したD値・z値）による推定であり、
特定の食材・菌種に対する公的機関の基準値ではありません。

実際に低温調理を行う際は、必ず各国・地域の保健当局や信頼できる情報源が示す
低温調理の安全ガイドライン（水温・中心温度・保持時間など）に従ってください。
このアプリが示す数値を、実際の調理における安全性の根拠として使用しないでください。
