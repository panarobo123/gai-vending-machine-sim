# 低温調理 熱モデルシミュレータ

鍋にお湯を張って加熱しながら食材を低温調理するプロセスを、湯・食材表層・食材中心の
3ノード熱モデルでブラウザ上でシミュレートします。

## 使い方

`thermal-model-simulator/index.html` をWebブラウザで開くだけで動作します（サーバー不要・依存ライブラリなし）。

## 動作の仕組み（シミュレーションモデル）

1. **投入直後の混合** — 沸騰した湯を鍋に入れた瞬間、湯と鍋（比熱・質量）の熱容量比で
   混合後の初期湯温が決まる。
2. **熱の出入り** — 以下の3種類の熱流を毎ステップ計算する。
   - `q_ws`：湯 → 食材表層（対流熱伝達、UA_ws = h·A）
   - `q_sc`：食材表層 → 食材中心（熱伝導、UA_sc = k·A/L）
   - `q_amb`：湯 → 周囲（保温方法に応じた放熱、UA_amb）
3. **温度の時間変化** — ヒーターの一定出力Pと上記熱流から、湯・表層・中心それぞれの
   温度変化を連立ODE（オイラー法）で数値積分する。湯温は沸点100℃でクランプされる。
4. **キープ率評価** — 目標温度±2.5℃の帯域に湯温が収まっている時間の割合を
   「キープ率」として算出する。

## 操作できるパラメータ

| 項目 | 範囲 | 効果 |
|---|---|---|
| 初期温 | 0〜45℃ | 食材・室温の初期条件 |
| 湯量（100℃） | 300〜8000mL | 投入する沸騰水の量 |
| 材料 | 鶏むね(63℃)／牛肉(57℃)／魚肉(45℃) | 目標中心温度が変わる |
| グラム数 | 50〜2000g | 食材の質量（表面積・体積に影響） |
| ヒーター出力 | 0〜100W | 加熱中に一定で加わる熱量 |
| 保温方法 | 蓋無し／蓋のみ／蓋+タオル巻き／発泡クーラー箱 | 周囲への放熱係数(UA_amb)が変わる |
| 倍速 | ×10／×60／×300 | 実時間1秒あたりの経過シミュレーション時間 |

## その他の機能

- 模式図・グラフ・数値モニタがシミュレーション結果とリアルタイムに連動します。
- 「数式を表示」ボタンで、モデルに使われている数式と現在条件下の係数値を確認できます。
- 調理完了時に条件と結果（投入直後湯温・平均湯温・キープ率など）を履歴として自動保存します
  （`window.storage` が利用可能な環境の場合）。
