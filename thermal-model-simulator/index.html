1. 投入直後の混合(瞬時)

Tw(0) = (Mw·cw·100 + C鍋·T0) / (Mw·cw + C鍋)

2. 熱の出入り(矢印に対応)

q_ws = UA_ws·(Tw − Ts) q_sc = UA_sc·(Ts − Tc) q_amb = UA_amb·(Tw − T0) P = ヒーター出力 (一定, 終了まで)

3. 温度の時間変化(連立ODE)

Cw·dTw/dt = +P − q_ws − q_amb (Tw≦100) Cs·dTs/dt = +q_ws − q_sc Cc·dTc/dt = +q_sc

4. 係数の定義

Cw = Mw·cw + C鍋 Cs = 0.6·Mm·cm / Cc = 0.4·Mm·cm UA_ws = h·A / UA_sc = k·A/L A = 0.08·Mm^(2/3), L = 0.015·(Mm/0.3)^(1/3)
