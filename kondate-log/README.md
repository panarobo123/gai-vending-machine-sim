# 献立ログ — ダイエット記録アプリ

食べたものと体重を記録し、目標カロリーまでの距離を測るブラウザ内完結の食事管理アプリです。

## 使い方

`kondate-log/index.html` をWebブラウザで開くだけで動作します（サーバー不要・依存ライブラリなし）。

記録・設定・自作食品はブラウザ内（`window.storage` が使えない環境ではそのタブのメモリ内のみ）に自動保存されます。機種変更や万一の消失に備えて、設定タブから JSON ファイルとして書き出し・読み込みができます。

## 画面構成

* **今日** — 日付を送って各日の摂取カロリー・PFC（三大栄養素）バランス・食事ごとの記録・体重とメモを確認/入力
* **食品** — 92品のプリセット食品データベース（カテゴリ・キーワード検索）＋自分で登録した食品
* **推移** — 直近14日間の摂取カロリーと体重の推移グラフ、目標との差などの統計
* **設定** — 性別・年齢・身長・体重・活動レベル、目標体重と減量ペース、目標カロリー/PFC比率、データの書き出し・読み込み・サンプル投入・全消去

## 計算ロジック

* 基礎代謝（BMR）は Mifflin-St Jeor 式、消費目安（TDEE）は BMR × 活動レベル係数で算出。
* 目標カロリーの自動計算は `TDEE − 減量ペース分（体脂肪1kg≒7700kcal換算）` を、性別ごとの下限（BMR×1.1、または男1500/女1200kcalの高い方）で下げ止まるよう算出。
* 食品は100gあたりの栄養価で保持し、選択した量（グラム／食品ごとの目安単位）に応じて按分計算。
