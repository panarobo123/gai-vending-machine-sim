# ダイエット管理アプリ

体重と食事を記録すると、目標体重に向けて1日に摂取すべきカロリーを自動計算してくれるダイエット支援WEBアプリです。

## 使い方

`diet-app/index.html` をWebブラウザで開くだけで動作します（サーバー不要・依存ライブラリなし）。記録データはブラウザの`localStorage`に保存されるため、同じブラウザで開けば前回の記録が復元されます（他の端末とは同期されません）。初回起動時（保存データがまだ無い状態）は、アプリに同梱されたサンプルデータ（`index.html`内の`SEED_DATA`）が初期値として表示されます。別のブラウザ・端末にデータを持ち運びたい場合は、「データのバックアップ」カードからJSONファイルとしてエクスポート／インポートできます。

1. 「プロフィール設定」で性別・年齢・身長・活動レベル・目標（減量／維持／増量）・週あたりの目標変化量・目標体重を入力して保存する
2. 「体重記録」で今日の体重を記録する（体重を記録していない場合は目標体重を仮の現在体重として計算します）
3. 「食事記録」で朝食・昼食・夕食・間食ごとに食べたものとカロリー（任意でP/F/C）を記録する。よく使う食品はプルダウンから選ぶと入力欄に自動入力される。「数量」欄（初期値1）で個数・杯数を指定すると、kcalとP/F/Cはその数量分で自動計算される（例：卵1個90kcalで数量2を指定すると180kcalで記録）
4. 画面上部のサマリーで、BMI・消費カロリーの目安（TDEE）・1日の目標摂取カロリー・残りカロリー・目標達成予測日を確認できる

## 計算方法

* **基礎代謝量（BMR）**：ミフリン・セントジオール方程式
  * 男性：`10×体重kg + 6.25×身長cm − 5×年齢 + 5`
  * 女性：`10×体重kg + 6.25×身長cm − 5×年齢 − 161`
* **消費カロリーの目安（TDEE）**：`BMR × 活動レベル係数（1.2〜1.9）`
* **1日の目標摂取カロリー**：
  * 減量：`TDEE − (週あたり変化量kg × 7700kcal ÷ 7)`
  * 維持：`TDEE`
  * 増量：`TDEE + (週あたり変化量kg × 7700kcal ÷ 7)`
  * ※体脂肪1kgあたり約7700kcalとして計算
* **BMI**：`体重kg ÷ (身長m)²`（日本肥満学会の基準で判定）
* 目標摂取カロリーが低すぎる場合（男性1500kcal未満・女性1200kcal未満の目安）は警告を表示します

## 主な機能

* プロフィール設定（性別・年齢・身長・活動レベル・目標・目標体重）
* 体重記録（日付ごとに記録・グラフ表示・削除）
* 食事記録（食事区分ごとの記録、よく使う食品のクイック入力、数量指定によるkcal・P/F/Cの自動計算、日付送り）
* 本日の摂取カロリーと目標カロリーの進捗バー
* 体重推移グラフ（目標体重ラインつき）
* 直近14日間のカロリー推移グラフ（目標カロリーラインつき、超過日は赤色表示）
* データのバックアップ（現在の記録をJSONファイルとしてエクスポート／インポート）
* 初回起動時の初期データ（`SEED_DATA`）をアプリ本体に同梱

## 自分の記録を初期値にしたい場合

「データのバックアップ」→「データをエクスポート」でJSONファイルを保存し、その内容を`index.html`内の`SEED_DATA`定数に置き換えることで、次回以降の初回起動時（保存データが無い環境）に自分の記録が初期値として表示されるようになります。

## 注意事項

このアプリの計算はあくまで一般的な目安です。持病がある方や大きく体重を変える場合は、医師や管理栄養士に相談してください。
