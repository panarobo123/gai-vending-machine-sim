# 生成AIを使ったシミュレーター集

このリポジトリは、生成AIを活用したシミュレーターのサンプルプログラムを収録しています。各サブプロジェクトの詳細は、それぞれのディレクトリ内のREADMEを参照してください。

## サブプロジェクト一覧

* [`vending-machine/`](vending-machine/README.md) — 生成AIを使った自動販売機シミュレーター
  CQ出版社の雑誌『Interface』2024年6月号の第２部第２章の記事で解説したプログラム一式。コード生成プロンプト（`vending-machine/docs/prompt.txt`）、クライアント側・サーバー側プログラムを含みます。
* [`watering-simulator/`](watering-simulator/README.md) — 1L耐圧ペットボトル水やり器シミュレータ
  負圧式・水封式の自動水やり器の挙動をブラウザ上でシミュレートするツール。サーバー不要・依存ライブラリなしで動作します。
